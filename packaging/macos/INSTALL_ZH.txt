LanternDesk · 灯塔桌面

将 LanternDesk.app 拖入 Applications，再从“应用程序”启动。
arm64 包适用于苹果 M 系列芯片；x86_64 包适用于 Intel。要求 macOS 13 或更新版本。

此版本采用 ad-hoc 临时签名，没有 Apple Developer ID 签名及公证。
请核对下载来源与 SHA-256；若系统阻止打开，可在“系统设置 → 隐私与安全性”中审查并手动允许此应用。
无需关闭 Gatekeeper 或系统完整性保护。

被控 Mac 需要授予 LanternDesk 屏幕录制与辅助功能权限；输入异常时按提示授予输入监控权限。
授予权限后退出并重新打开应用。

无需注册或登录账户。使用对端 ID 与访问密码，或由对端确认连接。
仅使用自己的服务器或 IP 直连，不使用 RustDesk 公共 ID／中继或公共 STUN。
未配置服务器时，输入被控端的可达 IP 直连，默认端口 TCP 21118；设备 ID 连接必须先配置自己的 hbbs/hbbr。
使用自建中转时，两端在“设置 → 网络 → ID/中继服务器”中导入相同配置，API 服务器留空。

构建使用软件视频编解码。此包未经过真实双机屏幕控制、麦克风与文件传输验收。
源代码与说明：https://github.com/Cbetula/lanterndesk
